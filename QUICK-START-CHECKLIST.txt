PHASE 2: DEPLOYMENT TO VERCEL (Estimated Time: 30 minutes)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Connect GitHub to Vercel
──────────────────────────────
1. Go to https://vercel.com/new
2. Click "Continue with GitHub"
3. Select your modernhub-ecommerce repository
4. Click "Import"
5. Vercel will auto-detect Next.js configuration
6. Click "Deploy"

⏱️ Deployment time: ~3-5 minutes

✓ Your store is now live at: modernhub-ecommerce.vercel.app


STEP 2: Configure Environment Variables in Vercel
─────────────────────────────────────────────────
1. In Vercel dashboard, click on your project
2. Go to Settings → Environment Variables
3. Add each variable below:

# STRIPE - PAYMENT PROCESSING
STRIPE_PUBLIC_KEY=pk_live_YOUR_PUBLIC_KEY
STRIPE_SECRET_KEY=sk_live_YOUR_SECRET_KEY
STRIPE_WEBHOOK_SECRET=whsec_YOUR_WEBHOOK_SECRET
NEXT_PUBLIC_STRIPE_PUBLIC_KEY=pk_live_YOUR_PUBLIC_KEY

# MAILGUN - EMAIL NOTIFICATIONS
MAILGUN_API_KEY=key-YOUR_API_KEY
MAILGUN_DOMAIN=sandboxXXXXX.mailgun.org
EMAIL_FROM=noreply@yourdomain.com
ADMIN_EMAIL=admin@yourdomain.com

# MONGODB - DATABASE
DATABASE_URL=mongodb+srv://username:password@cluster.mongodb.net/modernhub
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/modernhub

# AUTHENTICATION
NEXTAUTH_SECRET=your-super-secret-key-here-32-characters-minimum
NEXTAUTH_URL=https://yourdomain.vercel.app (or your custom domain)
ADMIN_PASSWORD=$2a$10$... (bcrypt hashed password)

4. Click "Save"
5. Go to Deployments tab
6. Click the latest deployment
7. Click "Redeploy"

✓ All environment variables are now loaded


STEP 3: Configure Stripe Webhook
─────────────────────────────────
1. Go to Stripe Dashboard → Webhooks
2. Click "Add an endpoint"
3. URL field: https://yourdomain.vercel.app/api/stripe/webhook
4. Select Events: 
   ☐ payment_intent.succeeded
   ☐ payment_intent.payment_failed
5. Click "Add endpoint"
6. Copy the Webhook Secret (whsec_...)
7. Add to Vercel environment variables
8. Redeploy

✓ Stripe will now send payment confirmations to your app


STEP 4: Connect Custom Domain (Optional but Recommended)
──────────────────────────────────────────────────────
1. In Vercel Project Settings → Domains
2. Enter your domain: yourdomain.com
3. Vercel shows you DNS records
4. Go to your domain registrar (Namecheap, GoDaddy, etc.)
5. Update nameservers to:
   - ns1.vercel-dns.com
   - ns2.vercel-dns.com
6. Wait 24-48 hours for DNS propagation
7. Check status in Vercel (should show "Valid Configuration")

✓ Your store is now at: yourdomain.com

ISSUES FOUND:

If something isn't working:

Payment Fails?
→ Check Stripe keys in Vercel environment
→ Verify webhook is set up

→ Test locally with: npm run dev

Emails Not Sending?
→ Verify Mailgun domain in environment
→ Check spam/promotions folder
→ Verify EMAIL_FROM is correct
→ Check Mailgun logs for errors

Admin Won't Load?
→ Verify NEXTAUTH_SECRET is set
→ Check ADMIN_PASSWORD is correct bcrypt hash
→ Clear browser cache
→ Check browser console errors

Database Error?
→ Verify DATABASE_URL is correct
→ Check MongoDB allows your Vercel IP
→ Test connection string locally
